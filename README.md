# 🎬 CINEMA LOG（映画レビュー＆感想記録サイト）

観た映画のあらすじ・評価・長文レビューを管理・閲覧できるWebアプリケーションです。
スマートフォンでの快適な操作性を意識し、画面遷移なしでスワイプ操作によって一覧と詳細を切り替えられるUIを実装しています。

## 🌐 公開URL
- **本番サイト（Vercel）**: `https://あなたのURL.vercel.app`

---

## ✨ 主な機能

1. **スマホライクなスワイプ画面遷移（SPA的UI）**
   - 映画カードのタップや左右の横スワイプ操作により、URLを変更せずスムーズに一覧画面と詳細画面をスライド切り替えできます。
   - 検索やジャンル絞り込みの状態を保持したまま各作品の詳細を確認できます。
2. **リアルタイム検索・ジャンル絞り込み・評価順並び替え**
   - 映画タイトル・監督名によるインクリメンタル検索（リアルタイム絞り込み）。
   - ジャンル別のワンタップフィルター機能。
   - 登録順・評価（★）が高い順のソート機能。
3. **microCMS連携によるコンテンツ管理と即時反映**
   - ヘッドレスCMS（microCMS）からポスター画像・基本情報・あらすじ・長文レビューを取得。
   - `force-dynamic` の設定により、CMS側で記事を公開・更新するとリロードのみで本番サイトへ即時反映されます。
4. **全ページ共通レイアウト**
   - `app/layout.tsx` による共通ヘッダー・フッターの配置と、未登録画像に対するフォールバック（No Image）表示に対応。

---

## 🏗 設計上の工夫（サーバーとブラウザの役割分担）

Next.js (App Router) の特性を活かし、処理の実行場所を明確に分離しています。

- **サーバー側（Server Components）**: `app/movies/page.tsx`
  - microCMSからの最新データ取得を担当。APIキーをブラウザに露出させず安全に通信します。
- **ブラウザ側（Client Components）**: `app/movies/MovieList.tsx` (`'use client'`)
  - 検索・絞り込み・並び替え、およびタッチ座標（`onTouchStart` / `onTouchEnd`）を用いた横スワイプ判定とスライドアニメーションをブラウザ内で完結させ、通信待ちのない高速な操作感を実現しました。

# 2. 環境変数の設定（.env.local を作成して以下を記述）
